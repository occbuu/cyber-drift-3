# results/ — what is here and which of it the paper uses

Everything the paper quotes is regenerated by one command and checked by another:

```
python -m experiments.open_set.paper_tables   # writes paper/paper_tables.md and .json
python scripts/check_claims.py                # every quoted number against those tables
```

## Final outputs — read these first

| path | what it is |
| --- | --- |
| `paper/paper_tables.md` | **Every table in the paper**, generated. Never edit by hand |
| `paper/paper_tables.json` | The same numbers, machine-readable; what `check_claims.py` reads |
| `paper/environment.json` | Machine, package versions, git commit, wall-clock per stage, a content hash per data split |

## Inputs to the tables — the experiment itself

Every directory below is written by the full-run driver (`experiments/open_set/run_full_experiment.py`)
and read by `paper_tables.py`. Deleting any of them breaks a table.

| path | produced by | feeds |
| --- | --- | --- |
| `scores/` | `capture_scores` — one `.npz` of calibration and test scores per (dataset, rotation, seed, panel) | everything; this is the only stage that trains models |
| `window_draws/` | `run_window` at n = 12,000, level corrections L = 1, 5, 100 | RQ1 gate (b), RQ2, the temporal comparison, the bootstrap |
| `window/` | `run_window` at the full calibration set | the window-size sweep (secondary) |
| `resolution/` | `run_resolution`; `resolution/panel/` holds the eight-detector barrier sweep | RQ1 gates (a) and (c), the prediction table |
| `operator/` | `run_operator_baseline` — the percentile threshold a SOC runs | the operator comparison |
| `budget/` | `run_budget` — cross-domain transfer and the label budget | RQ4 |
| `shift_gate/` | `run_shift_gate` — label-mix shift | RQ4 |
| `mondrian/` | `run_mondrian` — grouping by predicted class, port class, protocol | RQ3 Mondrian |
| `frontier/` | `run_frontier` — clairvoyant ceilings | the prediction table, RQ3 |
| `latency/` | `run_latency` — device path, floored against tail-lifted | the latency table |
| `ablation_geometry/`, `ablation_knn/`, `ablation_backbone.json` | component ablations | "what the method's name may claim" |
| `protocols/` | the legacy leave-one-attack-out runner (`run_full.py`) | nothing in the paper; kept so that runner still works |

`scores/` naming: `{dataset}_{rotation}_panel{A|B}_s{seed}.npz`. Panel A holds PCF (code
identifier `hedl`), CLOSR, EFC and RENOIR-DML; panel B holds ORI, DOC++, AIS-NIDS and usfAD.
Z1 captures omit the rotation (`cse2018_panelA_s13`). Other prefixes: `_T2_` time-ordered
split, `_Z3t70_` / `_Z3t90_` separability-threshold sensitivity, `_noevid_` evidential-term
ablation, `_tail_` tail-lifted scorer.

## Run bookkeeping

| path | what it is |
| --- | --- |
| `run_logs/` | Every driver log and every job-state file. `environment.py` reads the state files to report the cost of each stage; the driver's default state file is `run_logs/full_run_state.json` |

## Archive — not used by the paper

Nothing was deleted; `_archive/MOVES.md` lists every file that was moved and where it went.

| path | what it is | why it is not evidence |
| --- | --- | --- |
| `_archive/mock_and_pilot/` | mock tests (`mock_*`), pilots (`pilot_*`), the early three-RQ design (`three_rq*`), sanity runs, and exploratory studies that did not become part of the design | reduced conditions — two datasets, three seeds, earlier versions of the method. Several of their verdicts were later withdrawn |
| `_archive/superseded/ungrouped/` | rotations captured before the separability audit grouped twin attack families | held out a family whose twin stayed in training |
| `_archive/superseded/pointwise/` | RQ4 results computed before the level-budget correction | the training-conditional bound did not cover the procedure it was paired with |
